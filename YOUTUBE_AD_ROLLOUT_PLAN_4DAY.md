## 6) Users Online at Any Given Time (Direct Answer)

This estimate is for ad-driven incremental online users only.

Assumptions used:
- Average active session length from ad traffic: 6 minutes
- Main usage window each day: 14 hours (840 minutes)
- Peak concurrency multiplier vs daily average: x2.5 to x3.0

Formula:
- Average concurrent users from ads = usable site users/day x (session minutes / active-window minutes)

### Incremental Concurrent Users from Ads

| Scenario | Usable Users/Day | Avg Concurrent (Ads Only) | Peak Concurrent (Ads Only) |
|---|---:|---:|---:|

| Base | 30 | ~0.21 | ~1 |
| Upside | 76-77 | ~0.54-0.55 | ~1-2 |

Interpretation:
- At this budget, ad traffic alone will usually add around 0 to 2 concurrent users at a time.
- This is normal for a $125/day test and is still enough to validate funnel quality.

### Total Online Users (Ads + Existing Organic)

Use this:
- Total online at any moment = current organic baseline + ad-driven concurrent users.

Example:
- If your current baseline is 8-20 online, base-case ads likely move that to roughly 9-21 online, with brief peaks higher.

## 7) User Total Sensitivity (Quick Math)

At $500 total spend:

- Every $0.01 change in CPV moves total engaged views by about 1,587 views.
- Every +0.2% absolute CTR change moves total site clicks by about 22 clicks (base view volume).
- Every +5% relative lift in activation moves total activated users by roughly +2 to +4 users at this spend level.

## 8) Sign-Up Gate Impact on User Totals

Current reality:
- Users can browse quickly, but posting requires sign-up.

How this affects totals:
- It usually reduces activation from ad traffic unless expectation is clear before submit.

Low-effort improvement to protect totals:
- Signed-out users: button text should read Sign up to post.
- Signed-in users: button stays Send.

Expected impact from this copy change:
- Activation lift: +5% to +15% relative.
- On base totals, that is roughly +2 to +8 extra activated users over 4 days.

## 10) Practical Reality Check

- At $500 total, expect signal, not scale.
- Most likely outcome is tens of activated users, not hundreds.
- This is enough to decide whether to increase spend.

If total activated users land under 35, improve funnel before scaling.
If totals are 55+, consider a controlled increase in daily budget.
